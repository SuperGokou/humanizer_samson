# 评估方法与边界

目标是改善自然程度、清晰度与段落连贯性，同时保持事实、数据、引用、术语及论证强度。AI 检测结果是外部观察指标，不能作为学术准确性或作者身份的证明；不承诺降低或通过 GPTZero。

## 对照设置

对同一输入、模型、术语表、窗口大小，保存三个版本：原文、`--no-retrieval` 改写、指定学科的检索改写。候选参考实验应统一 `--allow-candidates`，并记录索引指纹。模型随机输出可能波动，应使用多个文本和多次实验，不能只挑分数好的结果。

人工盲评先隐藏版本来源，逐段检查：

| 指标 | 记录方式 |
| --- | --- |
| 自然程度与清晰度 | 1–5 分及具体句子理由 |
| 段落连贯性 | 指代、转折、因果连接是否恰当 |
| 内容保持 | 数字/对象、否定、相关与因果、限定语、引用错误数量 |
| 术语一致性 | 不允许的名称或术语替换数量 |
| 参考措辞重合 | 本次参考的连续 12 词重合；不能当作全网查重 |
| 实用性 | 改动句数、回退数量、人工修订时间 |
| 成本 | 实际模型、请求次数、prompt/completion tokens、耗时 |

`report.json` 的 0–100 评分是模型编辑判断。naturalness、clarity、style_match 越高表示越好；redundancy、rewrite_need 越高表示越需要修改。重叠窗口取中位数，同时保留每次观察及理由，避免把单一评分当作客观事实。

## 外部检测

自行向 GPTZero 等服务提交原稿和改稿后，将真实结果填写到运行目录的 `evaluation.csv`，记录 detector、detector_score、checked_at 和 notes。还应记录检测器版本/显示的量纲与全文或段落模式。默认结果留空；项目不会伪造检测分数，也没有自动提交第三方检测器。

## 本次验收范围

Finance 与 Science 各提供 8 句明确标注为合成的样本，含数值、术语、因果限定和占位引用。真实联网测试只验证模型调用、评分、改写、保护和复核链路。第一版指令下，两篇均保留原文；随后加入明确的精简目标与评分依据，且普通赘词标记不再错误地触发 Pro。完整实际次数和 token 见本机 `runs/verification.json` 与各次运行 `report.json`。

这些合成文本不能代表长篇真实论文、所有学科或检测器表现。当前语料正式审核库为空，候选库来自 299 篇待质量审核文章。上线前应增加真实授权论文盲评，审查解析质量、来源许可、风格适配与事实保持；不能将成功 HTTP 响应或低检测分数称为论文质量验证。
